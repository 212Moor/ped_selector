# 🎭 ped_selector

**Changez de personnage en un instant sur FiveM !**

`ped_selector` est une ressource FiveM permettant aux joueurs de modifier leur apparence en appliquant différents modèles de ped directement sur leur personnage.

## ✨ Fonctionnalités

- 👤 **Sélection de ped** : choisir le modèle de personnage souhaité.
- 🔄 **Changement de modèle** : remplacer son personnage actuel par un autre ped.
- 🎮 **Application instantanée** : appliquer le modèle sélectionné directement en jeu.
- 🎭 **Personnalisation** : utiliser différents modèles de personnages disponibles dans GTA V.
- 🛠️ **Utilisation simple** : changer de ped sans devoir modifier manuellement les fichiers du jeu.

## 📦 Installation

1. Téléchargez le projet depuis le dépôt GitHub.
2. Placez le dossier `ped_selector` dans le répertoire `resources` de votre serveur FiveM.
3. Ajoutez cette ligne dans votre fichier `server.cfg` :

   ```cfg
   ensure ped_selector
   ```

4. Redémarrez votre serveur ou démarrez la ressource depuis la console FXServer.

## 🎮 Utilisation

1. Connectez-vous à votre serveur FiveM.
2. Ouvrez le sélecteur de ped selon la méthode prévue par la ressource.
3. Choisissez le modèle de personnage que vous souhaitez utiliser.
4. Appliquez le modèle et profitez de votre nouveau personnage en jeu.

## 🧰 Compatibilité

- **Plateforme :** FiveM
- **Jeu :** Grand Theft Auto V
- **Serveur :** FXServer

## ⚠️ Informations importantes

- Certains modèles peuvent être incompatibles ou ne pas fonctionner comme prévu.
- Le changement de ped peut modifier les animations, les proportions et les capacités du personnage.
- Les permissions d'utilisation peuvent être configurées selon les besoins du serveur.
- Le fonctionnement en multijoueur dépend de l'implémentation de la ressource.
